# 📊 Sales Performance Dashboard | Microsoft Excel

## 📌 Project Overview

This project presents an **interactive Sales Performance Dashboard built in Microsoft Excel** to analyze order-level sales data and convert raw business data into meaningful, decision-ready insights.

The dashboard provides a clear overview of **revenue, orders, quantity sold, average order value, monthly trends, regional performance, product categories, sales channels, and top-performing products**.

The main objective was to design a dashboard that allows business users and managers to quickly monitor sales performance and identify growth opportunities.

## 🎯 Business Problem

A sales manager needs a centralized dashboard to answer important business questions:

- How much total revenue has been generated?
- How many orders have been placed?
- How many units have been sold?
- What is the Average Order Value?
- Which months generate the highest revenue?
- Which region performs best?
- Which product category contributes the most revenue?
- Which sales channel generates the most revenue?
- Which products are the top revenue generators?
- How does performance change by customer type and time period?

This project addresses these questions through an **interactive Excel dashboard**.

## 📈 Dashboard Analysis

### 1. Revenue by Month

A monthly revenue trend is used to identify sales patterns and fluctuations throughout the year.

**Key observations:**
- Highest monthly revenue: **November – ~$274K**
- Lowest monthly revenue: **July – ~$151K**
- The trend helps identify strong and weak sales periods.

---

### 2. Revenue by Region

The dashboard compares revenue across five regions.

| Region | Revenue |
|---|---:|
| North | ~$562K |
| Central | ~$557K |
| East | ~$468K |
| South | ~$444K |
| West | ~$421K |

**Insight:**  
The **North region** is the highest revenue-generating region, while **West** has the lowest revenue among the five regions.

## ✅ Data Quality Checks

Before developing the dashboard, important data-quality checks were considered:

- No blank column headers
- No fully blank rows
- Date values correctly recognized as dates
- Revenue and Quantity stored as numbers
- Consistent region and category names
- Order ID available for order counting
- Data structured correctly for PivotTables
